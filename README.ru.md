**Транслитерация, варианты написания и сопоставление личных имён из славянских и мусульманских стран.** Есть версии для **Python** и **TypeScript/JavaScript**: данные общие, результаты совпадают.

[English version →](README.md) · [TypeScript-пакет →](js/README.md)

У одного имени много законных латинских написаний. **Юрий** — это `Iurii` в загранпаспорте, выданном сегодня, `Yuriy` в паспорте 2005 года, `Yuri` в прессе, `Yury` в Википедии, `Jurij` в немецких документах и `Iouri` во французских. **محمد** — это `Muhammad`, `Mohammed`, `Mohamed`, `Mohammad`, `Mehmet` или `Magomed` в зависимости от страны. `translit-names` знает официальные стандарты, стоящие за этими написаниями, и реальную практику вокруг них:

```python
>>> from translit_names import transliterate, variants, similarity, mrz_name
>>> transliterate("Щербаков Юрий")                 # загранпаспорт РФ (ICAO Doc 9303)
'Shcherbakov Iurii'
>>> transliterate("Щербаков Юрий", "ru_bgn_pcgn")  # стандарт правительств США и Великобритании
'Shcherbakov Yuriy'
>>> variants("محمد", limit=6)
['Muhammad', 'Mohammed', 'Mohamed', 'Mohammad', 'Muhamad', 'Muhammed']
>>> similarity("Мухаммед Али", "Mohammed Ali")
0.985
>>> mrz_name("Щербаков", "Юрий")
'SHCHERBAKOV<<IURII<<<<<<<<<<<<<<<<<<<<<'
```

## Возможности

- **85 схем транслитерации для 22 языков.** У каждой — правовой источник, год, статус (действует / отменена / неофициальная практика), а официальные примеры из первоисточника служат юнит-тестами:
  - **восточнославянские**: русский (ICAO — загранпаспорта с 2013 г., ГОСТ Р 52535.1 — 2010–2013, приказ МВД № 310 — 1997–2010, советская «французская» система, BGN/PCGN, ГОСТ 7.79 A/B = ISO 9, ALA-LC, научная, Википедия, Telegram, Яндекс, Московское метро), украинский (постановление КМУ № 55 от 2010 г. со всеми 76 официальными примерами, системы 1996 и 2007 гг., ISO 9, ALA-LC), белорусский (паспортная практика, Инструкция 2023 г. со всеми 51 официальными примерами, 2007 г., МВД № 288, BGN/PCGN, ALA-LC, ISO 9);
  - **южнославянские**: болгарский (Закон о транслитерации 2009 г., включая правило -ия → -ia в конце слова, ISO 9, старые системы), сербский (гаевица, MRZ по ICAO, практическое `Dj`), македонский (официальная система 2008 г., BGN/PCGN, ISO 9), сербохорватская латиница → ASCII;
  - **тюркские и кавказские**: казахский (паспорт, латиница 2021 г., BGN/PCGN), узбекский (официальная латиница 1995 г., паспорт), киргизский, таджикский, туркменский, турецкий, азербайджанский (в т. ч. постановление Кабмина № 498 от 2020 г.), татарский, башкирский, чеченский/ингушский;
  - **арабская письменность**: арабский (ALA-LC, DIN 31635, UNGEGN 2017, BGN/PCGN, IJMES, Buckwalter, ICAO MRZ, практическая английская, египетская и магрибская «французская»), персидский (ООН 2012, BGN/PCGN, ALA-LC, практическая), урду, пушту;
  - **ICAO Doc 9303 §6.A** — свёртка любой латинской буквы с диакритикой (польский, чешский, словацкий, хорватский, словенский, турецкий, немецкий, скандинавские языки…).
- **Огласовка арабской письменности.** Имена пишутся без кратких гласных (محمد = m-ḥ-m-d). Гласные берутся из словаря огласованных имён, а для неизвестных имён — из шаблонов арабских имён (فاعل *Khalid*, فعيل *Karim*, مفعول *Mahmud*, أفعل *Ahmad*…).
- **Словарь имён: более 1100 кластеров** (славянские и мусульманские имена, частые фамилии, элементы арабских имён вроде *Abd*, *bin*, *-uddin*, *-ullah*). В каждом — написания во всех письменностях, принятые латинские формы по странам, засвидетельствованные варианты, уменьшительные формы и переводные эквиваленты.
- **`variants()`** — ранжированный список правдоподобных латинских написаний имени для поиска и связывания записей.
- **`similarity()` / `compare()`** — сопоставление имён между письменностями с учётом транслитерации. Работает через кластеры словаря и скелетные ключи, понимающие чередования (`kh/h/x`, `sh/ch/sch/sz`, `zh/j/dj`, `ks/x`, `-iy/-y/-ii`, `al-/el-/ul-`, `-uddin/-eddine`…). Добавляет Jaro–Winkler, выравнивает части имени в любом порядке, учитывает инициалы и отсутствующее отчество.
- **`mrz_name()`** — поле имени машиносчитываемой зоны паспорта по ICAO Doc 9303 (TD1/TD2/TD3, усечение), проверено на официальных примерах ICAO.
- **`detect_language()`** — язык имени по буквам: ґ є ї → украинский, ұ → казахский, ٹ ڈ ڑ → урду, ə → азербайджанский…
- **Очистка ввода**: нормализация Unicode, смешение латиницы и кириллицы (`Иванoв` с латинской *o*), варианты апострофа, арабские и персидские формы букв, татвиль, формы представления.
- **Ноль зависимостей**: чистый Python 3.9+, полная типизация (`py.typed`, mypy strict), есть утилита командной строки.

## Установка

**Python** (3.9+):

```bash
pip install git+https://github.com/artemmarus/translit-names.git
```

**TypeScript / JavaScript** (Node.js 18+, браузеры) — подробности в [js/README.md](js/README.md):

```ts
import { transliterate, variants, similarity, mrzName } from "translit-names";

transliterate("Щербаков Юрий");               // "Shcherbakov Iurii"
variants("محمد", { limit: 4 });               // ["Muhammad", "Mohammed", "Mohamed", "Mohammad"]
similarity("Мухаммед Али", "Mohammed Ali");   // 0.985
```

TypeScript-пакет — порт Python-версии, собранный из тех же JSON-данных. CI проверяет, что обе версии дают одинаковый результат на ~11 700 эталонных случаях (`scripts/gen_parity_fixtures.py` → `js/test/parity.test.ts`). Для браузера есть облегчённая точка входа `translit-names/core` без словаря имён (≈128 КБ gzip вместо ≈255 КБ).

## Использование

### Транслитерация

```python
from translit_names import transliterate, list_schemes

transliterate("Щербаков Юрий")                    # 'Shcherbakov Iurii'   (язык определён: ru)
transliterate("Щербаков Юрий", "ru_mvd_310")      # 'Shcherbakov Yuriy'   (паспорта 1997–2010)
transliterate("Ксения", "ru_mvd_310_fr")          # 'Xeniia'              (советская «французская»)
transliterate("Олександр Згурський")              # 'Oleksandr Zghurskyi' (украинский, КМУ 2010)
transliterate("Нұрсұлтан Назарбаев")              # 'Nursultan Nazarbayev'
transliterate("محمد بن سلمان")                     # 'Muhammad bin Salman'
transliterate("عبد الرحمن", "ar_ala_lc")           # 'ʻAbd al-Raḥmān'
transliterate("حسین")                             # 'Hossein'             (персидский)
transliterate("Христо Стоичков", language="bg")  # 'Hristo Stoichkov'
```

Если схема не указана, язык определяется по буквам и берётся его схема по умолчанию: действующая паспортная для кириллических языков и практическая английская для арабской письменности. Для имён без характерных букв (Олександр — допустимое и русское написание) лучше явно указать `language=`. Все схемы перечислены в [docs/SCHEMES.md](docs/SCHEMES.md).

### Варианты написания

```python
from translit_names import variants

variants("Юрий", limit=6)      # ['Iurii', 'Yuri', 'Yury', 'Yuriy', 'Iury', 'Iuri']
variants("Хусейн", limit=6)    # ['Khusein', 'Hussein', 'Gusein', 'Husein', 'Khuseyn', 'Khusain']
variants("Евгений Щербаков")   # 'Evgenii Shcherbakov', 'Yevgeny Shcherbakov', 'Evgeny Shcherbakov' …
```

### Сопоставление имён

```python
from translit_names import similarity, compare, is_match, name_key

similarity("Щербаков Юрий", "Yuri Scherbakov")   # 0.977
similarity("Hasan", "Husayn")                    # 0.6  — это два разных имени
is_match("Магомед", "Mehmet")                    # True — одно и то же имя (Мухаммад)

r = compare("Ivanov Ivan Ivanovich", "IVAN IVANOV")
r.score            # 0.96 — отсутствие отчества почти не штрафуется
r.unmatched_left   # ('Ivanovich',)

name_key("Мухаммед Али") == name_key("Mohammed Ali")   # True — ключ для блокировки в базах
```

У каждой пары частей имени указана причина совпадения:
- `exact` — точное совпадение;
- `same-name` — одно имя по словарю;
- `skeleton` и `skeleton-coarse` — совпадение скелетных ключей;
- `fuzzy` — нечёткое сходство строк;
- `initial` — инициал;
- `diminutive` — уменьшительная форма (Саша ~ Александр, 0.86);
- `equivalent` — перевод, а не транслитерация (Michael ~ Михаил, 0.80);
- `different-names` — оба имени известны, но разные; оценка не выше 0.6.

Порог `is_match` по умолчанию — 0.88.

### MRZ паспорта

```python
from translit_names import mrz_name, parse_mrz_name

mrz_name("Щербаков", "Юрий")                 # 'SHCHERBAKOV<<IURII<<<<<<<<<<<<<<<<<<<<<'
mrz_name("Əliyev", "İlham")                  # 'ALIYEV<<ILHAM<<<<<<<<<<<<<<<<<<<<<<<<<<'
parse_mrz_name("AL<BASRI<<HUDA<MUHAMMAD")    # ('AL BASRI', 'HUDA MUHAMMAD')
```

### Командная строка

```bash
translit-names "Щербаков Юрий"                     # Shcherbakov Iurii
translit-names translit --all "Юрий"               # все русские схемы рядом
translit-names variants --scores "Хусейн"
translit-names match "Мухаммед Али" "Mohammed Ali" # код выхода 0, если совпадает
translit-names mrz Щербаков Юрий
translit-names detect "Нұрсұлтан"
translit-names schemes -l kk
cat names.txt | translit-names -s uk_kmu_2010      # по одному имени в строке
```

## Как это устроено

1. **Схемы — это данные.** Каждый стандарт — JSON-файл в [`src/translit_names/data/schemes/`](src/translit_names/data/schemes): таблица букв плюс контекстные правила (начало и конец слова, предыдущая и следующая буква, классы букв). Формат описан в [docs/data-format.md](docs/data-format.md). Движок заменяет самое длинное совпадение и восстанавливает регистр по исходнику (`Щ` → `Shch`, `ЩЕРБАКОВ` → `SHCHERBAKOV`). Каждый `sample` в файле схемы — это тест.
2. **Арабская письменность сначала огласовывается.** Огласовки во входном тексте сохраняются. Известные имена заменяются огласованной формой, а в практических схемах — принятым написанием. Неизвестные огласовываются по шаблону, остальное транслитерируется побуквенно.
3. **Варианты** объединяют все схемы языка, словарь и правила чередований ([`variant_rules.json`](src/translit_names/data/variant_rules.json)) с оценкой правдоподобия.
4. **Сопоставление** переводит оба имени в латиницу и делит на части. Части выравниваются в оптимальном порядке и сравниваются по кластеру словаря, затем по скелетным ключам, затем по Jaro–Winkler.

### Бенчмарк

`python scripts/benchmark.py` проверяет работу без словаря на парах, взятых из словаря (порог 0.88):

| Метрика | Значение |
|---|---|
| Полнота для одного имени, латиница ↔ латиница, **без словаря** | 0.80 |
| Полнота, родная письменность ↔ латиница, без словаря | 0.93 |
| Ложные срабатывания на случайных разных именах | 0.000 |
| Доля принятых русских написаний в `variants()` без словаря (топ-30) | 0.78 |
| Скорость (чистый Python) | ~5000 сравнений/с |

Со словарём (по умолчанию) все написания известных имён совпадают.

## Точность и ограничения

- **Единственно правильного написания не существует.** Страны меняют паспортные таблицы: Россия меняла их в 1997, 2010 и 2013 годах. Россия, Украина, Болгария, Беларусь, а с 2026 года и Киргизия позволяют гражданину выбрать своё написание. Для поиска используйте `variants()` и `similarity()`, а не сравнение строк.
- **Паспортная практика ряда стран не опубликована.** Схемы для паспортов Казахстана, Киргизии, Таджикистана, Туркменистана, Узбекистана, Азербайджана и Беларуси построены по наблюдаемой практике. Они помечены `status: informal`, а в заметках каждой описано, на чём она основана.
- **Неогласованные арабские имена вне словаря угадываются.** Шаблоны верны для частых моделей арабских имён, но могут ошибаться. Если важна точность, подавайте текст с огласовками.
- **В ICAO Doc 9303 есть известные ошибки** кириллической таблицы: сербское Г→H, Һ→C, македонское GJ стоит не у той буквы. Пакет их не повторяет.
- **ISO 233 и часть DIN 31635** платные, поэтому эти схемы опираются на опубликованные описания (см. `notes` в файлах).
